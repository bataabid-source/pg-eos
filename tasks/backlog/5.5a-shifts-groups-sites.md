## Scope (verbatim shapes, SCR §2.1–§2.4)

- `hr.shifts` — code · name_ar/en · starts_at/ends_at · crosses_midnight · grace_minutes · days_of_week · site_id → `platform.sites` · is_active · version. Replaces the free-text `hr.teams.shift` (kept, marked legacy).
- `hr.shift_assignments` — employee_id · shift_id · group_id (nullable) · valid_from/valid_to · assigned_by · version. **One active assignment per employee per date** (exclusion constraint on the date range).
- `hr.shift_groups` — the GM's "transport group": shift_id · code · name_ar · group_type ∈ {transport · warehouse · other} · lead_employee_id (the driver) · vehicle_id → `tms.vehicles` (nullable) · site_id (the group's own attendance site) · starts_at/ends_at override · is_active · version.
- `platform.sites` — kind ∈ {warehouse · office · client_pickup · housing · other} · account_id (required when client_pickup) · warehouse_id (nullable) · names · address · geo_lat/geo_lng · radius_m (default `platform.thresholds` `att.geofence_radius_m = 500`, D-141 Q30b) · contact_phone · is_active · version. `hr.employees.default_site_id` references it.
