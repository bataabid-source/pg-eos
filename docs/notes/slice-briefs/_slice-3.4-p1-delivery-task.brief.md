## Decisions (defaults — one CHANGELOG line each)
1. Guard = ONE function `tms.guard_vehicle_assignable()` (naming after `hr.guard_commission_daily_status()`, 0033/0035), `security definer`, `search_path = pg_catalog, pg_temp` (RLS on tms.vehicle_documents must not hide an expired row), attached as `trg_guard_vehicle_assignable` BEFORE INSERT OR UPDATE OF vehicle_id on `tms.delivery_tasks` AND `tms.routes`; fires only when `new.vehicle_id is not null` and (INSERT or `new.vehicle_id is distinct from old.vehicle_id`); rule = fleet's own: `exists (select 1 from tms.vehicle_documents d where d.vehicle_id = new.vehicle_id and d.expiry_date < (now() at time zone 'Asia/Kuwait')::date)` → `raise exception … using errcode = 'check_violation', constraint = 'inv_c4_1_vehicle_assignable'` (SQLSTATE 23514, message names INV-C4-1, the vehicle id and WBS 3.4 part 1). Idempotent (`create or replace`, `drop trigger if exists` before `create trigger`).
2. Same migration 0046 adds `version int not null default 1` to `tms.delivery_tasks` (CLAUDE.md "every mutable aggregate has a version column"; precedent 0008/0013/0014/0017). No other column. Slug: `0046_B_delivery-tasks-version-vehicle-guard.sql`.
3. 4. `create-delivery-task`: input = `outboundOrderId`, `expectedVersion` (outbound order), `recipientName`, `recipientPhone`, `area`, `block`, `street`, optional `building`, `addressText`, `governorate`, `correlationId`; INV-C4-2 (doc 40 L274) enforced in domain/ (missing OR whitespace-only area/block/street/phone → typed 422 error; the contract already trims and refuses whitespace (`.trim().min(1)`); the domain check and its property test repeat it, i18nKey `tms.task.create.addressIncomplete`), never derived silently from `ship_to_*` (the order has no block/street).
