## S6 — "Multi-entity client, group-level hold blocks all entities"

> Given client "RETAIL" has contracts with PST, PDL and PCC and credit_limit 15000. And an overdue
> PST invoice pushes exposure above the limit. When the nightly job runs. Then credit_hold = true.
> And a new PST outbound order is rejected with reason "credit hold". And a new PDL delivery task
> is rejected with the same reason. And a new PCC queue for "RETAIL" is rejected.

Checked against the actual codebase:
- **PST outbound order rejection** — needs WBS **2.11** (outbound order creation). Not built —
  it's the row lane 1 is queued for *next*, after 1.11.
- **PDL delivery task rejection** — needs `modules/tms`. **The module does not exist at all**
  (confirmed: no `modules/tms` directory).
- **PCC queue rejection** — needs `modules/cc`. **The module does not exist at all** (confirmed:
  no `modules/cc` directory) — that's WBS 5.1, not started.
- **"the nightly job runs" setting `credit_hold` from overdue-invoice exposure automatically** —
  1.8 built `SetCreditHold`/`ReleaseCreditHold` as manual CFO/GM commands only. No scheduled job
  evaluates AR exposure and calls them automatically; `billing.*` (AR/overdue-invoice data) does
  not exist yet either (Phase 4, 0/18 done).

Zero of S6's four `Then` lines are checkable today.

## S10 — "Price exception, floor enforced on every write path"

> Given ST-01 min_price = 2.500. When a quote line at 2.100 is submitted via UI, via API, and via
> import. Then all three are rejected with the floor price in the message. When GM approves a
> price_exception with reason, validity and review date. Then the line saves referencing the
> exception. And the eventual invoice line has price_source = "exception".

- **Via API** — exists and is already proven: `UpsertQuoteLine` (WBS 1.6) enforces the floor,
  32 assertions across `modules/sales/tests/manage-quote/*` cover it, including the exact
  below-floor-rejected acceptance shape.
- **Via UI** — no quote-entry screen exists anywhere in `apps/admin` (0.19 shipped a Decision
  Inbox, 1.9 shipped a read-only Customer 360; neither lets anyone create or edit a quote line).
- **Via import** — no quote-line import channel exists (1.6 built no CSV/bulk-import command for
  quotes; `ImportPriceListLines` from 1.2 imports *price list* lines, a different aggregate).
- **`GrantPriceException` → the line saves referencing the exception** — exists and is tested
  (WBS 1.2/1.6).
- **"the eventual invoice line has `price_source = exception`"** — needs an invoice line. Billing
  (Phase 4) is 0/18 done; no `billing.invoice_lines` write path exists anywhere.

One of five `Then`/`And` lines is checkable today (the API-channel floor rejection, already proven
by 1.6's own suite — not a new deliverable). Four are not.
