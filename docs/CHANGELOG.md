SALES_REP creates and builds lines; SALES_MGR moves commercial_review→finance_review; CFO approves finance_review→approved NORMALLY, but a GM must approve instead whenever any line cites a price exception OR the quote's estimated margin is below 10% (doc 40 §C2 + D-blueprint 02 §165) — GM is always accepted either way, being the superset role. `ReturnToDraft` lets a reviewer send a quote back for edits (the only board-compliant way to leave commercial_review/finance_review backward, since the enum has no separate "returned" status).

## 1.4 — Pricing engine: exception → contract → segment → list → pending (2026-09-25)

- Read-only resolution engine, no writes, no API endpoint, no state machine (mechanism slice, precedent WBS 2.8 — resolving a price is a computation, not a persisted lifecycle transition). Lives under `modules/sales` (the lock the Master granted) and reads `catalog.*`/`sales.*` tables directly via SQL, same cross-schema-read pattern the golden slice already uses (no TypeScript cross-module import, so boundaries lint is untouched).
- Waterfall, first match wins: price exception (flat `qty × approved_price`) → the account's active contract's own price list (`status='active'`, non-internal, entity-matched; falls through to the next branch if that list has no priced line for the service — does NOT stop at "contract found but unpriced") → the account's segment's price list → the entity's standard (no segment/client) price list → `pending` (never a zero price). Every list branch filters `is_internal=false` and `currency='KWD'`; a non-KWD-only line is treated as no-line (same fall-through).
- Tiered/progressive calculation (INV-C1-3): a flat line (`tier_from`/`tier_to` both null) is `qty × price`; a ladder walks tiers ascending, each tier's billable quantity = `max(0, min(qty, tier_to ?? qty) − tier_from − free_units)`, summed at that tier's own rate — never the last tier's rate applied to the whole quantity. A malformed ladder (inverted or zero-width tier, gap, overlap) throws `MalformedTierLadderError` rather than silently miscalculating.
