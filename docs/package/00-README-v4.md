## 1. ما هذه النسخة

v4 هي **إعادة بناء كاملة** لحزمة PG-EOS (46 ملفاً في v3 → 59 ملفاً هنا + أطلس النظام (D-blueprints)) بعد تدقيق شامل على أربعة أبعاد — منطقي · برمجي · تشغيلي · إداري — نُفِّذ بخمسة عناقيد تدقيق موازية، وبتشغيل فعلي للمخطط على PostgreSQL 16، وبتحقق برمجي لكل ادّعاء داخل `begin; … rollback;`.

الحصيلة: **231 ملاحظة موثّقة بالدليل ورقم السطر** (59 حرجة · 130 متوسطة · 42 صياغية) عولج منها 215 كلياً و9 جزئياً، و5 محوّلة إلى قرارات المدير العام، و2 مسجّلتان. التفصيل الكامل في `AUDIT-REPORT-v4.md`، والتغييرات ملفاً ملفاً في `CHANGELOG-v4.md` و`_changelog/`.

## 4. كيف تُستخدم
1. **تحقق من المخطط أولاً** (يحتاج PostgreSQL 16):
   ```bash
   cd A-governing/database && PGDATABASE=pgeos ./apply.sh --recreate
   ```
   المتوقع: صفر أخطاء · 175 جدولاً · 3,330 موقعاً · كل حارس مانع (G1–G13) = 0 · `G-SEED` = 0 · G6 غير مانع (مهمة WBS 0.16).
2. **أنشئ المشروع** باتّباع `PROJECT-SETUP-GUIDE.md` خطوة بخطوة (المستودع · نسخ الحزمة والعدة · القاعدة المحلية · أول جلسة بـ`BOOTSTRAP-v5.md`).
3. **ابدأ 0.1** — لا قرار يحجب المهام 0.1–0.20 (Part 6).

## 5. ما يحتاج توقيع المدير العام (لا يحجب البناء، مفصّل في AUDIT-REPORT-v4 §6)
- **الاعتماد الإنشائي لبلاطة المستودع** (2,439.75 طن المحسوبة مقابل 1,420.5 في التقرير الإنشائي — فرق 72%): كل أرقام الطاقة معلَّقة عليه (وثيقة 19 §10).
- **خروج البيانات من الكويت** (رأي قانوني — WBS 7.9) قبل أي بيانات عميل حقيقية على Tier 0/2.
- **السعر التحويلي الداخلي** بين الكيانات — بدونه لا تُحسب ربحية PCC/PDL بدقة.
- 8 مسائل أخرى موسومة `[GM DECISION REQUIRED]` داخل الوثائق (قائمتها الكاملة مصنّفة في `_changelog/VERIFY-v4.md` §د). لكل واحدة قيمة مؤقتة مطبَّقة في v4.
