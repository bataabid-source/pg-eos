# ترتيب أسبقية السعر

عند تسعير أي حدث، يبحث النظام بهذا الترتيب ويتوقف عند أول تطابق:

```
1. استثناء سعري ساري للعميل والخدمة       → price_source = 'exception'
2. سعر في ملحق أسعار العقد                 → price_source = 'contract'
3. سعر قائمة شريحة العميل                  → price_source = 'segment'
4. سعر القائمة القياسية                     → price_source = 'list'
5. لا سعر → الحدث يبقى pending ويظهر في تقرير الاستثناءات
```

**لا يُفوتر حدث بسعر صفر أو مفقود إطلاقاً.** الدورة تتوقف لذلك السطر وتُرفع للمدير المالي. هذا أهم ضابط ضد الإيراد الضائع الصامت.

**بوابة الحد الأدنى — مفروضة على كل مسارات الكتابة:** الشاشة والواجهة البرمجية والاستيراد كلها تمرّ بطبقة التحقق نفسها (P5). سطر عرض دون `min_price` يُرفض بالقيمة في الرسالة، ولا يُقبل إلا بـ **استثناء سعري باعتماد `GM`** بسبب ومدة سريان وتاريخ مراجعة — وعندها تُسجَّل الفاتورة بـ `price_source = 'exception'`.
