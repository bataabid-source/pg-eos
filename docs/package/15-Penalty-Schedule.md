## 3-1 مسار التظلّم — الفجوة التي تُسدّ

النظام القديم كان يُصدر الإنذار ويخصم **بلا حالة تظلّم**. النتيجة: منازعة عمالية بلا أثر موثّق يُثبت أن الموظف مُكِّن من الدفاع.

### الأعمدة الأربعة التي يضيفها v4 ولماذا

| العمود | الجدول | السبب |
|---|---|---|
| **`signed_by`** + **`signer_role`** | `disciplinary_cases` | **السلطة الهرمية غير مفروضة اليوم إطلاقاً**: الجدول لا يحوي عمود موقِّع أصلاً (الموجود `reported_by` و`approved_by` و`grievance_decided_by`)، فلا سبيل للتحقق من «الموقّع يدير المخالف» ولا من «الدرجة ضمن سقفه» |
| **`routed_to`** | `disciplinary_cases` | نصّ §3 يقول «**يُحال آلياً للمستوى المخوَّل**» — لا «يُرفض». فالرفض الصامت يُسقط الواقعة، وإعادة التوجيه تحفظها |
| **`art35_override_by`** | `disciplinary_cases` | تجاوز مهلة الخمسة عشر يوماً **بقرار GM مسجَّل** لا بتعطيل قيد |
| **`min_degree`** | `penalty_schedule` | **16 بنداً في اللائحة تبدأ من D2 أو D4** (خانة D1 فيها «—») مثل `CLI-06` و`CLI-09` و`WRK-08` و`CON-05` و`SYS-03` و`ATT-04`. فأول واقعة على بند يبدأ من D2 تُطبَّق بدرجة 1 = «—» أي **بلا جزاء** |
| **`is_fraud`** | `penalty_schedule` | `ADR-28` يشترط «قضية احتيال مفتوحة ⇒ `driver_trust = 0`» بالأكواد **`CLI-02` · `CLI-03` · `CLI-04` · `CLI-06` · `CLI-09` · `ATT-07` · `ATT-08` · `WRK-08`**. بلا عمود يميّزها يحتاج محرّك الثقة قائمة أكواد **مكتوبة في الكود** — وهو ما يمنعه قيد 40 §A5 «No magic numbers» |

### قيدا المادتين 35 و37 — الصيغة الصحيحة

**الصيغة التالية نُفِّذت واختُبرت على قاعدة `pgeos` الحيّة** في مخطط مؤقت داخل `begin; … rollback;` بأربع حالات (النتائج الكاملة في `_changelog/CHANGELOG-ADM.md`).

```sql
-- ❌ ما كان في v1 — يفرض القاعدة الخطأ:
--   constraint art35_15_days check (incident_date >= proven_date - interval '15 days')
--   يقيس المسافة بين الواقعة والثبوت، بينما نصّ الوثيقة يقيس
--   المسافة بين الثبوت وتوقيع الجزاء.

-- ✅ المعتمد في v4:

-- (أ) قيد منطقي مساند: لا يسبق الثبوتُ الواقعةَ
alter table hr.disciplinary_cases
  add constraint art35_incident_before_proof
  check (proven_date >= incident_date);

-- (ب) م.35 — توقيع الجزاء خلال 15 يوماً من ثبوت المخالفة
alter table hr.disciplinary_cases
  add constraint art35_15_days
  check (
    signed_at is null                 -- لم يُوقَّع بعد
    or art35_override_by is not null  -- تجاوز GM مسجَّل
    or signed_at <= proven_date + 15
  );

-- (ج) م.37 — خمسة إجراءات إلزامية لا أربعة
alter table hr.disciplinary_cases
  add constraint art37_due_process
  check (
    penalty_type <> 'deduction'
    or (
      notified_at              is not null   -- ☐ إبلاغ كتابي
      and statement_heard                    -- ☐ سماع الأقوال
      and defence_investigated               -- ☐ تحقيق الدفاع
      and investigation_minutes_url is not null  -- ☐ محضر التحقيق بالملف
      and decision_notified_at is not null   -- ☐ إبلاغ كتابي بالجزاء
    )
  );
```

**أثر التصحيح على المادة 35 — قانوني لا شكلي:**

| الحالة | القيد القديم | القيد الجديد |
|---|---|---|
| واقعة 01/01 ثبتت 01/06 ووُقِّعت 10/06 — **مشروعة** | **تُرفض** ❌ | **تمرّ** ✅ |
| واقعة 01/01 ثبتت 01/06 ووُقِّعت 20/06 — **سقطت بالتقادم** | **تمرّ** ❌ | **تُرفض** ✅ |
| واقعة ثبتت قبل سنة وتُوقَّع اليوم | تمرّ ❌ | تُرفض ✅ |
| تجاوز GM مسجَّل | لا وجود له | تمرّ ✅ بأثر موثّق |

**وأثر التصحيح على المادة 37:** كان القيد يفرض **أربعة** إجراءات من الخمسة ويغفل **محضر التحقيق** (`investigation_minutes_url`) — وهو **الدليل الوحيد القابل للإبراز أمام جهة العمل**، بينما نصّ الوثيقة و40 §C7 («five due-process fields mandatory») يوجبان الخمسة.

### مُشغِّل السلطة الهرمية — المواصفة السلوكية

> **SQL هذا المُشغِّل يكتبه وكيل المخطط في 13B؛ والمواصفة الكاملة مسجَّلة في `_changelog/ADM-SCHEMA-NEEDS.md` §4-2.** ما يلي السلوك الملزِم:

`hr.check_penalty_authority()` — `before insert or update` على `hr.disciplinary_cases`:

1. **سلسلة الإشراف:** يتحقق أن `employee_id` يقع في سلسلة `hr.employees.reports_to` الصاعدة من `signed_by` — أو أن `signer_role = 'GM'`.
2. **سقف الدرجة بحسب المنصب:** مشرف **D1–D2** · مدير (`WH_MGR`/`DEL_MGR`/`SALES_MGR`/`FLEET_MGR`/`HOUSING_SUP`) **D1–D3** · `GM` **D1–D4**.
3. **الفصل للمدير العام وحده:** `penalty_type = 'dismissal'` (أو `applied_degree = 4`) ⇒ `signer_role = 'GM'`.
4. **إعادة التوجيه لا الرفض الصامت:** عند تجاوز الموقّع سقفه أو خروجه عن سلسلة الإشراف، **يُحفظ الصفّ** بـ`routed_to` = أقرب مخوَّل صاعد و`routed_reason`، و`status = 'pending_authority'` — ولا يصير `signed` إلا بتوقيع المخوَّل.
5. **التظلّم لمستوى أعلى:** `grievance_decided_by` **أعلى من `signed_by`** في السلسلة نفسها — لا يبتّ في التظلّم من وقّع الجزاء.

### دالة الدرجة المستحقة — مع `min_degree`

```sql
create or replace function hr.next_penalty_degree(p_employee uuid, p_code text)
returns int language sql stable as $$
  select least(
           4,
           greatest(
             (select min_degree from hr.penalty_schedule where code = p_code),
             1 + count(*)::int
           )
         )
  from hr.disciplinary_cases
  where employee_id  = p_employee
    and penalty_code = p_code
    and incident_date >= current_date - interval '12 months'
    and status in ('issued','upheld','applied','carried_forward')
$$;
```

### قيد الفئات التسع

```sql
alter table hr.penalty_schedule
  add constraint valid_category
  check (category in ('attendance','work','vehicle','client',
                      'safety','conduct','housing','custody','system'));
```

## 4-1 حالة خاصة: غرامات العملاء لسائقي العمولة

غرامة العميل على سائق العمولة **تخفيض لقاعدة العمولة لا خصم من أجر** — فلا تدخل سقف المادة 38. أما سائق الراتب فالغرامة خصم يدخل السقف.

⚠️ **هذا تكييف قانوني يحتاج تأكيد المستشار القانوني.**

# 5. لوحة سجل الجزاءات

| القسم | المحتوى |
|---|---|
| الجزاءات هذا الشهر | بالفئة · بالدرجة · بالإدارة |
| **الحصيلة المالية** | إجمالي الخصومات — متطلب م.40 |
| التظلّمات | مفتوحة · مؤيَّدة · ملغاة · **نسبة الإلغاء** |
| المتكررون | موظفون بلغوا الدرجة 3 أو 4 |
| **البنود الأكثر تكراراً** | مؤشر على خلل في التدريب أو الإجراء لا في الأشخاص |
| بلا إجراءات م.37 مكتملة | جزاءات عالقة لا يمكن اعتمادها |
| متجاوزو 15 يوماً | وقائع سقطت لتأخر الرصد |
| الخصومات المرحَّلة | تجاوزت سقف 5 أيام |

**مؤشران يُقرآن معاً:**
- **نسبة إلغاء التظلّمات مرتفعة** → الجزاءات تُصدر بلا تحقيق كافٍ
- **بند واحد يتكرر عبر موظفين كثيرين** → المشكلة في الإجراء أو التدريب، لا في الأشخاص
